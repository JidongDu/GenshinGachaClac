使用说明

这个工具算什么

给定「投入多少抽」和「要拿到哪些角色 / 武器各几个」，算出全部达成的概率、期望抽数与分位数，并把星辉返利带来的额外抽数放在一起对比。

顶部对比条怎么读

  • 不含星辉返利：只有预算时能达成的概率，精确 DP 计算，没有采样误差
  • 含星辉返利：把抽卡返还的星辉换成抽数后，实际达成的概率（蒙特卡洛模拟）
  • 右侧返利多出：两者差几个百分点、平均多几抽

左侧 ① 输入

  • 本期卡池：角色池① / 角色池② 各选 1 个 UP 五星 + 3 个 UP 四星；武器池选 2 把 5★ 和 5 把 4★。点开下拉可搜索名字，候选带头像；选「＋ 自定义…」可输入任意新角色 / 新武器。
  • 目标与预算：总投入抽数（最大 2500）+ 四个目标各要几个（个数不设上限）。每行会显示对应 UP 的头像和名字，填 0 表示不要。
  • 初始状态：角色池已垫抽数 / 首金小保底还是大保底 / 连歪次数；武器池已垫抽数 / 命定值。
  • 个人仓库：角色命座（0–6，-1 = 未拥有）与武器是否拥有。星辉返利完全依赖这份数据，改完可点「导出」保存。

右侧 ② 结果

  • 达成概率曲线：金色实线 = 不含返利，蓝色虚线 = 含返利，竖虚线是你的预算
  • 结果分解：全部达成 / 角色齐但武器不足 / 角色未齐
  • 星辉来源：四种稀有度各贡献多少抽
  • 校验：用蒙特卡洛独立复核精确值，两者应在 1σ 内

卡池与保底规则

  • 一期 = 角色池① + 角色池②（共享垫抽、大保底、捕获明光）+ 武器池（两把 UP 共池，定轨先①后②）
  • 武器换定轨会清零命定值；UP 角色本身是常驻角色时，歪出来的常驻有 1/8 概率也算命中
  • 策略「先角色后武器」：角色拿齐再抽武器、剩余抽数全部投入，在给定卡池下是最优的

星辉返还

5★ 角色首次 0 / 重复 10 / 满命 25
4★ 角色首次 0 / 重复 2 / 满命 5
5★ 武器首次 0 / 之后 10
4★ 武器首次 0 / 之后 2
兑换5 星辉 = 1 抽，不限购
只统计本期抽卡产生的返还；达标即停手，所以「实际消耗」通常小于预算。

概率口径

  • 角色池：0.6% / 74 抽起每抽 +6% / 90 硬保底 / 小保底 50% / 捕获明光 5% / 连歪 3 次必中
  • 武器池：0.7% / 63 抽起每抽 +7% / 80 硬保底 / 75% 出 UP / 命定值上限 1
  • 四星：50% 出 UP 四星；未触发 UP 时按官方「平稳机制」在角色 / 武器之间加权—— 连续不出角色时角色权重升高（255 起，17 抽后每抽 +2550），武器同理；武器池基数 300 / 14 抽后 +3000

保存与更新

  • 仓库改完点「导出 roster.js / roster.json」，覆盖 data/ 下同名文件，刷新即生效
  • 游戏出了新角色 / 武器：python3 sync_wiki_data.py
  • 补全头像图标：python3 build_assets.py

命令行

python starlight.py --pulls 360 --targets 1,1,1,0
python starlight.py --pulls 360 --targets 1,1,1,1 --w1 焚曜千阳 --w2 静水流涌之辉

--targets 顺序：角色①,角色②,武器①,武器②
